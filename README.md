# Звонилка — эмулятор USSD (PWA)

Веб-приложение, которое на телефоне выглядит как **стандартная звонилка**
(Google Phone / AOSP): вкладки «Недавние», «Контакты», «Клавиатура»,
звуки клавиш (DTMF), экран вызова.

Смысл: набираете код **`*147#`** → идёт «псевдо-загрузка» (прогресс-бар,
как при настоящем USSD-запросе) → выводится **текст, который вы заранее
задали в скрытых настройках**.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Вся звонилка (интерфейс + логика, один файл) |
| `manifest.json` | PWA-манифест (запуск в полноэкранном режиме) |
| `sw.js` | Service Worker (работа оффлайн) |
| `icon-192.png`, `icon-512.png` | Иконка приложения |

## Как запустить на телефоне

### Вариант 1 — GitHub Pages (проще всего)
1. Залейте файлы папки `web-dialer` в репозиторий на GitHub.
2. Settings → Pages → Source: branch `main`, папка `/ (root)` → Save.
3. Откройте ссылку `https://ваш-логин.github.io/репозиторий/` в Chrome на телефоне.

### Вариант 2 — любой хостинг
`Netlify Drop` (просто перетащить папку), `Vercel`, `surge.sh` и т.п. Нужен HTTPS — это требование браузеров для PWA.

### Вариант 3 — локально для проверки
Откройте `index.html` прямо в браузере. Работает, но иконки/полноэкранный режим появятся только при HTTPS.

## Как сделать «как обычное приложение» (на весь экран)
После открытия на телефоне:
- **Chrome**: меню ⋮ → «Добавить на главный экран» → «Установить».
- Начнёт открываться в полноэкранном режиме (`display: standalone`), без адресной строки — как настоящая звонилка.

## Скрытые настройки
- **Вход:** долгое нажатие на строку поиска вверху (или на круглый аватар справа).
- **PIN по умолчанию:** `0000` (меняется в настройках).
- Код USSD, по которому срабатывает запрос: по умолчанию `*147#` (меняется).
- **Текст ответа** — то, что показывается после «загрузки».
- Задержка ответа (1–30 сек), звук клавиш, вибрация, название.

Все настройки хранятся локально в браузере (localStorage) и сохраняются
между сеансами.

## Поведение
- `*147#` (или другой заданный код) → диалог «Идёт обмен данными с сетью…» → ответ.
- Любой другой `*…#`-код → такой же поток USSD.
- Обычный номер → экран вызова с таймером и кнопкой завершения.
- Долгое нажатие на «0» даёт `+`, долгое нажатие на удаление стирает всё.
